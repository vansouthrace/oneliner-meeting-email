## About

An entry for the [make.fun](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9) bounty "The Meeting That Should Have Been an Email": one joke about a meeting that should have been an email. The joke is not that the meeting ran long — it is that the meeting outlived its own follow-up email.

## Entry

> This meeting ran so long the follow-up email about it was scheduled, held, and minuted before we finished debating the agenda for the follow-up meeting.

## How to run

Requires Node 22.18+:

```sh
node main.ts
```

It writes the entry to `/output/entry.txt`.
